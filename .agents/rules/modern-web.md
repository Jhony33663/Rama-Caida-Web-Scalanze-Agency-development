# Google Chrome Modern Web Guidance

When generating, editing, or optimizing HTML, CSS, client-side JS, and Elementor custom styles/scripts for this site:
1. Always apply modern web standards from `https://github.com/googlechrome/modern-web-guidance`:
   - Native modern CSS: logical properties, subgrid, modern color spaces (oklch), container queries, CSS nesting.
   - Native web platform primitives: native `<dialog>`, popovers, modern form validation, accessible semantics (`aria-*`, landmark roles).
   - Core Web Vitals (CWV): modern image formats (AVIF/WebP), `loading="lazy"`, `fetchpriority="high"` for hero images, modern font display (`font-display: swap`).
   - Clean client-side JavaScript: native modern APIs over bloated polyfills.
